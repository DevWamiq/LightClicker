PC Tools by Wamiq fluid background attribution

This website uses a universal fluid background system:
- WebGL fluid effect for supported devices.
- Custom 2D canvas fallback for unsupported/blocked WebGL.
- Static CSS glow fallback if scripts are blocked.

The WebGL effect is a modified version of the MIT-licensed WebGL Fluid Simulation.

Reference/source:
https://github.com/rocksdanister/WebGL-Fluid-Simulation
Original WebGL Fluid Simulation by Pavel Dobryakov.

The script has been modified for:
- PC Tools by Wamiq dark theme
- cyan/blue/teal/green/violet color palette
- cursor-following website background behavior
- no visible GUI
- readability behind website content

See the source project for original license details.
