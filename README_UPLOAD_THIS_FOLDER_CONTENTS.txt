This universal fluid patch makes the live website effect work for more people:

1. WebGL fluid for supported browsers/devices.
2. 2D canvas live fluid fallback if WebGL fails or is blocked.
3. Static glowing background if scripts are blocked.
4. Cache-busting added so visitors stop seeing old files.

Important files added/updated:
- assets/pc-fluid.js = loader
- assets/pc-fluid-webgl.js = WebGL fluid effect
- assets/pc-fluid-fallback.js = 2D fallback effect
- style.css
- index.html
- privacy.html / terms.html / eula.html

Important update files:
- /latest.json = LightClicker
- /cpslab/latest.json = CPS Lab
- /timerforge/latest.json = TimerForge
