Privacy Policy

Effective date: 2026

PC Tools by Wamiq respects user privacy. Our tools are designed to run locally on the user's device and avoid unnecessary data collection.

1. Information we do not collect

LightClicker does not include advertising trackers, telemetry systems, or background analytics collection inside the app.

2. Local settings

The app may save local settings such as hotkeys, engine mode, activation mode, click location mode, manual coordinates, and saved positions, and window preferences on the user's device for convenience.

3. Update checking

LightClicker may check a public update file such as latest.json to determine whether a newer version is available or whether a minimum supported version is required.

4. Website hosting

The official website may be hosted using GitHub Pages or similar static hosting. Hosting providers may collect standard server logs such as IP address, browser type, referrer, and request time for operational and security purposes.

5. Downloads

Software downloads may be hosted using platforms such as GitHub Releases. Those platforms may process basic technical information according to their own policies.

6. Changes

This policy may be updated when new tools, features, or hosting services are added. The latest version will be published on the official website.

Summary: LightClicker runs locally, avoids telemetry, and only accesses the internet for update checking when enabled.
