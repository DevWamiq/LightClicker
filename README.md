# PC Tools by Wamiq

**PC Tools by Wamiq** is a collection of clean, lightweight Windows utilities built for speed, testing, automation, and control.

This repository hosts the official website and release downloads for PC Tools by Wamiq, including **LightClicker** and **CPS Lab**.

## Available Tools

### LightClicker

LightClicker is a clean Windows autoclicker built for fast, smooth, and controlled clicking.

**Features:**

- Up to 1000 CPS
- Custom hotkeys
- Toggle and hold modes
- Saved positions
- Coordinate clicking
- Emergency stop
- Windows Turbo mode
- Built-in update checker

### CPS Lab

CPS Lab is a local Windows CPS testing utility designed for smooth click-speed testing without browser lag.

**Features:**

- Click-only CPS testing
- Timed test modes
- Live CPS, average CPS, peak CPS, and total clicks
- Left, right, and middle click counters
- Live CPS graph
- Consistency score
- Rank system
- Best results history
- Built-in update checker
